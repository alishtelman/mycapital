# Дизайн-система MyCapital

MyCapital использует светлые нейтральные поверхности, приглушённые зелёные акценты и одну тёмную карточку для свободных денег на главной. Основная навигация сохраняет прежние разделы. Ширина боковой панели на десктопе — 184 px. Название страницы находится в основном контенте.

## Визуальные ориентиры

- Copilot Money показывает сумму и смысл показателя рядом, группирует операции и использует приглушённую тёмную тему. [Copilot Money](https://www.copilot.money/)
- Monarch делает суммы сопоставимыми в строках и подписывает сегменты диаграмм. [Monarch](https://www.monarch.com/landing/budgeting-tools)
- Revolut группирует баланс и ближайшие действия вокруг текущей задачи. [Revolut](https://www.revolut.com/)
- Apple Wallet даёт карточке чёткую визуальную иерархию и размещает детали за раскрытием. [Apple Wallet](https://www.apple.com/wallet/)
- Sure использует последовательные представления счетов и операций и доступный для просмотра исходный дизайн. [Sure](https://github.com/we-promise/sure)

## Токены

Токены в `app/design-tokens.css`. Светлую и тёмную палитры выбирает существующий атрибут `data-theme` на корневом элементе.

| Назначение | Использование |
| --- | --- |
| `--page`, `--surface`, `--soft` | Фон приложения, карточки и мягкая подложка |
| `--ink`, `--muted`, `--line` | Основной текст, пояснения и граница в 1 px |
| `--accent`, `--accent-hover`, `--accentInk` | Основное действие и его состояния |
| `--green`, `--danger`, `--attention`, `--focus` | Состояния, предупреждения и клавиатурный фокус |
| `--feature*` | Поверхность, текст и границы тёмного блока свободных денег |
| `--type-*` | Заголовок страницы 26–30 px, секции 17 px, основной текст 14 px, подписи 12 px |
| `--radius-*` и `--space-*` | 8 px для контролов, 12 px для карточек, шкала 4/8/12/16 px |
| `--control`, `--tap` | Основная кнопка 40 px, на мобильном не менее 44 px |
| `--icon-stroke` | Толщина 1,65, размеры 16/18/20/24 px по контексту |

## Компоненты

| Компонент | Правило |
| --- | --- |
| `Amount` | Передавайте целочисленную сумму в тиынах и знак отдельным аргументом. Компонент вызывает существующий форматтер `money` и держит число и ₸ на одной строке. |
| `AccountCard` | Одинаковая последовательность иконки, названия, суммы и chevron. Детали помещаются внутрь карточки. |
| `FinancialRow` | Название и описание слева, сумма справа. `onClick` делает строку кнопкой с chevron. Без обработчика строка остаётся информационной. |
| `PaymentRow` | Использует ту же сетку и принимает статус рядом с датой. |
| `Progress` | Передавайте долю от 0 до 100 и осмысленную метку. Перерасход обозначается вариантом `over`. Суммы и цвет сегментов диаграмм сопровождаются легендой. |
| `SectionHeading` | `page` создаёт заголовок страницы, остальные заголовки обозначают блоки. Описание и действие передаются по необходимости. |
| `Status` | Нейтральный статус по умолчанию, `success` и `attention` для смысловых состояний. Смысл выражается текстом. |
| `Blank` | Одно короткое сообщение внутри пустого раздела. |
| `Button` | Основной вариант для ключевого действия, `outline` для второстепенного, `ghost` для менее заметного текстового действия. |
| `Disclosure` | Нативный `details/summary` с клавиатурной поддержкой. Chevron 16 px выравнивается справа и поворачивается при раскрытии. |

## Проверка

В Chrome проверены главная, месяц, платежи, счета, кредиты, аналитика, история, настройки, меню «Ещё», цели, бюджет, покупки и диалог операции. Обе темы проверены при ширине 1440 и 390 px. На 390 px проверенные страницы помещаются без горизонтальной прокрутки, видимые компоненты `Button` имеют высоту от 44 px. Снимки до и после сохраняют одинаковые демонстрационные данные и разрешения.

Скриншоты — [docs/design-screenshots](./design-screenshots/). Проверки репозитория — lint, typecheck, 67 тестов и production build.
